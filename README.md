# Portfolio – Web Projects

A showcase of modern, high-performance web applications built with React, Next.js, Vue.js, and more.

---

## 🛠️ Tech Stack
- React, Next.js, Vue.js, Nuxt.js
- TypeScript, JavaScript, Tailwind CSS
- Framer (for animations)
- REST APIs, Responsive Design

---

## Getting Started

```bash
git clone https://github.com/shwetampandit/portfolio-main.git
cd portfolio-main
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
